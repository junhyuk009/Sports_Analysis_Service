# 2팀 2차 프로젝트 기획서

> 작성일: 2026-11-24 / 버전: v0.1 / 프로젝트명: 골(Goal)든 타임

## 1. 프로젝트 개요
- 주제: 해외축구(EPL) 분석 및 하이라이트 더빙 서비스
- 해결하려는 문제: 해외축구 정보와 실시간 중계 및 승부 예측을 한곳에서 확인하기 어렵다. 팀·선수 정보, 경기 일정·결과, 실시간 텍스트 중계가 여러 사이트에 흩어져 있고, 하이라이트 영상이 사용자가 원하는 시점에 올라오지 않는 등의 불편함이 있다.
- 목표 사용자: 해외축구(EPL) 경기 결과·선수 기록을 자주 찾아보는 국내 축구 팬, 특정 팀을 응원하며 경기 예측과 하이라이트를 즐기려는 사용자
- 개발 목표 및 기대 효과:
  - 팀·선수 정보, 경기 일정·결과, 실시간 텍스트 중계·라인업을 한 화면 흐름에서 조회
  - 자연어로 묻고 데이터 근거와 함께 답을 받는 AI 검색·챗봇 제공
  - 과거 경기 기록으로 학습한 모델로 경기 전 승부(홈승/무/원정승) 예측 제공
  - 하이라이트 영상을 Perso API로 다국어 더빙해 언어 장벽 해소
  - 응원팀 기반 개인화 화면과 적중률 포인트제 미니게임으로 재방문 유도
- 프로젝트 범위(포함/제외):
  - 포함: 회원가입(ID·비밀번호·닉네임, ID·닉네임 중복 확인)·로그인, 응원팀 설정·개인화, 팀 정보(팀 설명·수상 기록은 API 제공 범위 내)·선수 조회, 경기 일정·결과, 실시간 텍스트 중계·라인업(포메이션 표시가 어려우면 텍스트 대체), AI 검색·챗봇, AI 승부 예측, 하이라이트 더빙(팀 결과 화면에 배치)
  - 선택: 승부 예측 미니게임(적중률 포인트제)
  - 제외(후순위 보완점): 검색 자동완성, 댓글·커뮤니티, 리그 확장(EPL 외), AI 질문 페이지 팀 소식, 자동 작성 해설 문장, 편집·더빙·재배포 권한이 확인되지 않은 영상 사용

## 3. 기술 스택
| 구분 | 기술 | 선정 이유 |
|---|---|---|
| 프론트엔드 | Streamlit | Python만으로 화면을 빠르게 구성할 수 있어 짧은 개발 기간에 적합, 데이터·차트 시각화가 쉬움 |
| 백엔드 | FastAPI | 비동기 처리로 외부 API(GOAL·Perso) 호출과 더빙 상태 조회에 유리, 자동 API 문서(Swagger)로 팀 간 규격 공유가 쉬움 |
| AI 모델/API | GOAL API(축구 데이터), Perso API(영상 더빙), AI API(AI 검색·답변 생성), scikit-learn(LogisticRegression·RandomForest 승부 예측) | 축구 데이터·더빙은 외부 API로 확보하고, 승부 예측은 해석과 평가(Accuracy·Macro F1·Log Loss)가 쉬운 모델로 시작 |
| 데이터 저장 | PostgreSQL, 파일 저장소(영상) | 회원·경기·이벤트·예측·더빙 이력 간 관계(PK/FK)를 관리하기 좋고, 중복 방지 제약조건 적용 가능. 영상은 파일로 두고 DB에는 위치만 저장 |
| 배포 | 클라우드(서비스 미정) | 11일차 실서비스 검증을 위해 FastAPI 서버·Streamlit·PostgreSQL을 외부에서 접속 가능하게 배포. 서비스는 비용·무료 범위 확인 후 확정 |

## 5. 성공 기준 및 위험
- 핵심 기능 완료 기준:
  - 회원가입 시 중복 ID·닉네임이 거부되고, 비밀번호는 해시로만 저장된다.
  - EPL 팀·선수·경기 일정·결과가 중복 없이 조회되고, 진행 중 경기의 이벤트가 갱신 주기 안에 반영된다.
  - AI 검색이 예시 질문셋에 데이터 근거와 함께 답하고, 범위 밖 질문에는 안내 문구를 출력한다.
  - 승부 예측이 경기 후 정보 없이 생성되고, 시간순으로 분리한 평가에서 Accuracy·Macro F1·Log Loss가 기록된다.
  - 권한이 확인된 하이라이트(또는 대안 영상) 1건 이상이 선택한 언어로 더빙되어 재생된다.
- 배포 성공 기준: 배포 URL에서 팀 외부 사용자가 회원가입 → 로그인 → 경기 조회 → AI 검색 → 승부 예측 → 더빙 영상 재생까지 핵심 시나리오를 오류 없이 수행한다.
- 예상 위험(API 비용, 개인정보, 일정 등) 및 대응:
  - API 비용·호출 제한: GOAL API·AI API·Perso API 호출 제한과 과금 확인 → 동기화 주기 조절, DB 캐싱, AI 답변 결과 재사용
  - 영상 권한: 영상 링크 조회 권한과 편집·더빙·재배포 권한은 별개 → 1일차부터 권한 확인, 불가 시 직접 만든 통계·경기 요약 영상으로 대체
  - 데이터 제공 범위: 팀 설명·수상 기록·포메이션 등이 API에서 제공되지 않을 수 있음 → 제공 항목만 표시, 라인업은 텍스트로 대체
  - 개인정보·보안: 수집 정보는 ID·닉네임으로 최소화, 비밀번호 해시 저장, API 키는 `.env`로 관리하고 Git에 커밋 금지
  - 예측 모델 신뢰성: 경기 후 정보가 입력에 섞이는 데이터 누수 → 학습·평가 기간을 시간순으로 분리하고 특징 생성 단계에서 점검
  - 일정: 13일 안에 기능이 많음 → 필수 기능 우선, 미니게임은 핵심 기능 완료 후 진행, 보완점은 이번 범위에서 제외
